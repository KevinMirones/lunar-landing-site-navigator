# Specs S01 to S05 implemented

## What was done

| Spec | Status | What it brings |
| --- | --- | --- |
| [S01](../specs/S01-escenarios.md) | done | Comparing the same site on different dates, durations or masts |
| [S02](../specs/S02-enlaces-compartibles.md) | done | A link that opens the same comparison in another browser |
| [S03](../specs/S03-ci-y-despliegue.md) | in progress | Continuous integration, rate limit and security headers; deployment is still missing |
| [S04](../specs/S04-buscador-de-puntos.md) | done | Heat map around a point and the five best places nearby |
| [S05](../specs/S05-mejores-fechas.md) | done | The five best landing dates of the year |

Each spec is on its own branch, one on top of another: `feat/s01-escenarios`, `feat/s02-enlaces-compartibles`, `feat/s03-ci-despliegue`, `feat/s04-buscador-de-puntos` and `feat/s05-mejores-fechas`. The last one contains all five.

## How the work was done

- The logic was written test first: each test was seen to fail before the code was written.
- Each spec was also checked in a real browser, against the development server and against the built app.

## What was measured

| Measure | Result |
| --- | --- |
| Automated tests | 104, all passing (there were 16) |
| Recomputing six 90-day scenarios | under 300 ms |
| Point search, coarse grid | 0.6 s |
| Point search, fine grid (about 1260 cells) | 3.9 s |
| Scoring a year of landing dates | under 100 ms |
| Playback with the heat map open | 144 frames per second |
| Compressed JavaScript | 260 KB |

## What came up along the way

- [Rounding a point by 16 m changed its link from 100% to 93%](2026-11-14-06-dieciseis-metros.md).
- [A five-month delay takes the ridge from 100% to 28% sunlight](2026-11-14-07-estaciones-lunares.md).
- The security headers do not break the built app: it was checked with the same browser tests.

## What is left of this block

- **S03:** push the branches to see continuous integration go green, choose a host and deploy, and decide whether the DEM goes into the repository.
- **Browser tests:** they were run with temporary scripts that are not in the repository. It would be worth bringing them in before [S14](../specs/S14-robustez-y-calidad.md).
- **Pitch:** the figures in [PITCH.md](../PITCH.md) are still those of the MVP; the two new findings are not in it yet.

# Specs S01 a S05 implementadas

## Qué se hizo

| Spec | Estado | Lo que aporta |
| --- | --- | --- |
| [S01](../specs/S01-escenarios.md) | hecha | Comparar el mismo sitio en fechas, duraciones o mástiles distintos |
| [S02](../specs/S02-enlaces-compartibles.md) | hecha | Un enlace que abre la misma comparación en otro navegador |
| [S03](../specs/S03-ci-y-despliegue.md) | en curso | Integración continua, límite de peticiones y cabeceras de seguridad; falta desplegar |
| [S04](../specs/S04-buscador-de-puntos.md) | hecha | Mapa de calor alrededor de un punto y los cinco mejores lugares cercanos |
| [S05](../specs/S05-mejores-fechas.md) | hecha | Las cinco mejores fechas de alunizaje del año |

Cada spec está en su propia rama, una sobre otra: `feat/s01-escenarios`, `feat/s02-enlaces-compartibles`, `feat/s03-ci-despliegue`, `feat/s04-buscador-de-puntos` y `feat/s05-mejores-fechas`. La última contiene las cinco.

## Cómo se trabajó

- La lógica se escribió con la prueba primero: cada prueba se vio fallar antes de escribir el código.
- Cada spec se comprobó además en un navegador real, contra el servidor de desarrollo y contra la versión compilada.

## Qué se midió

| Medida | Resultado |
| --- | --- |
| Pruebas automáticas | 104, todas pasan (eran 16) |
| Recalcular seis escenarios de 90 días | menos de 300 ms |
| Buscador de puntos, malla gruesa | 0.6 s |
| Buscador de puntos, malla fina (unas 1260 celdas) | 3.9 s |
| Puntuar un año de fechas de alunizaje | menos de 100 ms |
| Reproducción con el mapa de calor abierto | 144 fotogramas por segundo |
| JavaScript comprimido | 260 KB |

## Lo que salió por el camino

- [Redondear un punto 16 m cambiaba su enlace de 100% a 93%](2026-11-14-06-dieciseis-metros.md).
- [Un retraso de cinco meses lleva la cresta de 100% a 28% de luz](2026-11-14-07-estaciones-lunares.md).
- Las cabeceras de seguridad no rompen la app compilada: se comprobó con las mismas pruebas de navegador.

## Qué queda de este bloque

- **S03:** subir las ramas para ver la integración continua en verde, elegir alojamiento y desplegar, y decidir si el DEM entra en el repositorio.
- **Pruebas de navegador:** se ejecutaron con scripts temporales que no están en el repositorio. Convendría incorporarlas antes de [S14](../specs/S14-robustez-y-calidad.md).
- **Guion:** las cifras de [PITCH.md](../PITCH.md) siguen siendo las del MVP; los dos hallazgos nuevos aún no están en él.
